Tentang Materi

Course React JS ini dirancang untuk membantumu menguasai salah satu library front-end paling populer di dunia. Kamu akan belajar dari dasar hingga mahir: komponen, props, state, hooks, routing, hingga deployment.

Cocok untuk developer yang sudah menguasai HTML, CSS, dan JavaScript dasar. Semua materi disusun step-by-step dengan contoh kode sederhana dan studi kasus nyata.

Apa yang akan kamu pelajari?


  • Memahami konsep dasar React, Virtual DOM, dan cara kerjanya
  • Setup proyek React dengan Vite dan memahami struktur folder
  • Menulis JSX dan membedakannya dengan HTML biasa
  • Membuat komponen reusable dengan props
  • Mengelola state lokal dengan useState untuk interaktivitas
  • Menampilkan list data dengan .map() dan conditional rendering
  • Menggunakan useEffect untuk efek samping (fetch API, localStorage)
  • Berbagi data antar komponen dengan useContext
  • Membuat navigasi multi-halaman dengan React Router
  • Berbagai cara styling: inline, CSS Modules, dan Tailwind CSS
  • Operasi CRUD lengkap dengan Axios dan API eksternal
  • Menyimpan data ke localStorage agar tetap ada setelah refresh
  • Membangun project Todo List dari awal sampai selesai
  • Deploy aplikasi React ke Vercel
